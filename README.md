# ショート動画メーカー（試作品）

使いたい場面をいくつか切り抜いて、つなげて1本の字幕つき縦型（9:16）ショート動画を作る Web アプリの試作品です。
処理はすべて使う人の端末（ブラウザ）の中で行われ、動画が外部サーバーに送られることはありません。

## 使い方

1. **動画を選ぶ**：手元の動画ファイルを選択します（選んだ直後に音声を読み込むので、そのまま待ってください）。
2. **切り抜き範囲を決める**：プレビューを再生して、使いたい場面の「ここから」「ここまで」を押します。数字で直接指定もできます。
   - 範囲は何か所でも追加できます（1か所だけでもOK）。重なる範囲は追加できません。
3. **文字起こし**：選んだ範囲の音声だけを文字起こしします（動画全体よりずっと早いです）。
   - 精度は2種類から選べます。精度優先（whisper-small、初回ダウンロード約250MB）／速さ優先（whisper-base、約70MB）。既定は速さ優先です。
   - 完了すると、範囲の端は字幕の切れ目（セグメント境界）に合わせて自動で整います。
   - 文字起こしの結果は、そのままリストでタップして直せます（誤字の修正用）。
4. **ショート動画を作る**：選んだ範囲を順につなげて、再生しながら録画する方式で書き出します。
   - 完成したらその場で再生確認とダウンロードができます。
   - 書き出し形式は端末・ブラウザによって変わります（mp4 または webm）。

## 技術メモ

- 文字起こし：[transformers.js](https://github.com/xenova/transformers.js)（whisper-small／whisper-base、quantized）を Web Worker 内で実行（画面が固まらないように）。音声は 16kHz モノラルにデコードして渡します。
- 書き出し：ffmpeg.wasm は使わず、Canvas（1080×1920、ぼかし背景＋フィット描画＋字幕描画）＋ MediaRecorder で記録します。複数範囲は順にシークしながらつなぎます。
- 字幕は大きく太く白文字＋黒縁取りで描画し、数字＋単位（％・円・倍・人・年など）と「」内は黄色で強調します。
- スマホ優先のモバイルファースト設計（ボタン・入力欄はタップしやすい大きさ）。広い画面ではプレビューと操作パネルの2カラムになります。

## 注意点

- 速さ優先（whisper-base）は精度が低めで、誤字の訂正が多くなりがちです。短い切り抜きなら精度優先がおすすめです。
- 範囲と範囲のつなぎ目では、一瞬だけ映像が止まって見えることがあります。
- 試作品のため、ブラウザや端末によっては動作しない場合があります。

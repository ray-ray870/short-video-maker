# ショート動画メーカー（試作品 v1）

動画を入れて、切り取りたいセリフを書くだけで、字幕つきの縦型（9:16）ショート動画を作る Web アプリの試作品です。
処理はすべて使う人の端末（ブラウザ）の中で行われ、動画が外部サーバーに送られることはありません。

## 使い方

1. **動画を選ぶ**：手元の動画ファイルを選択します。
2. **文字起こし**：「文字起こしする」を押すと、音声を自動で文字起こしします。
   - 初回は音声認識モデル（Xenova/whisper-small、約250MB）のダウンロードで数分かかることがあります。Wi-Fi 推奨です。
3. **切り抜き範囲を決める**：切り取りたいセリフと前後の秒数・最大秒数を入れて「切り抜き範囲を決める」を押します。
   - 範囲は文の切れ目（セグメント境界）に合わせて自動で決まります。開始・終了は手で直すこともできます。
4. **字幕を直す**：範囲内の字幕をタップして、その場で文字を修正できます（誤字の修正用）。
5. **ショート動画を作る**：再生しながら録画する方式で書き出します（30秒の動画なら約30秒かかります）。
   - 完成したらその場で再生確認とダウンロードができます。
   - 書き出し形式は端末・ブラウザによって変わります（mp4 または webm）。

## 技術メモ

- 文字起こし：[transformers.js](https://github.com/xenova/transformers.js)（Xenova/whisper-small、quantized）をブラウザ内で実行。音声は 16kHz モノラルにデコードして渡します。
- 書き出し：ffmpeg.wasm は使わず、Canvas（1080×1920、ぼかし背景＋フィット描画＋字幕描画）＋ MediaRecorder で記録します。
- 字幕は大きく太く白文字＋黒縁取りで描画し、数字＋単位（％・円・倍・人・年など）と「」内は黄色で強調します。
- スマホ優先のモバイルファースト設計（ボタン・入力欄はタップしやすい大きさ）。広い画面ではプレビューと操作パネルの2カラムになります。

## 注意点

- 長い動画の文字起こしは重い処理です。長い動画はパソコン推奨、スマホでは短い動画でお試しください。
- 自動の文字起こしには誤字が出ることがあります。書き出し前に字幕を直してください。
- 試作品のため、ブラウザや端末によっては動作しない場合があります。
